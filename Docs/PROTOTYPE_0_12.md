# Forbidden Memories Reborn — Prototype 0.12 AI Lab

## Goal
Create an offline, repeatable benchmark for the adaptive opponent brain.
This milestone **measures** training outcomes; it does not claim that the AI
has already become stronger. A worse post-training win rate is a valid result.

## What was implemented
- A .NET 8 headless executable (no Unity Editor required) in tools/Reborn.AiLab.
- Seeded synthetic 40-card monster-only decks and a scripted reference player.
- A scripted reference opponent as a baseline, plus the adaptive opponent
  evaluated before and after a fixed number of training duels.
- An isolated in-memory learning profile for training. No overwriting player
  saves, no cloud data and no copyrighted disc content.
- An outcome report containing wins, losses, unresolved games, win rate,
  average turns, attacks, training completion and learned tactic values.
- A regression self-test for reproducibility and consistent results accounting.
- A GitHub Actions artifact with the report generated for each push.
- Strict bounded runs (1-250 training duels, 1-250 evaluation duels,
  100 half-turns maximum per duel).

## Running the benchmark from Windows
Install .NET 8 SDK (for the independent benchmark; the Unity game still uses
Unity 6000.3.28f1). In the Reborn project directory:

    dotnet run --project tools/Reborn.AiLab/Reborn.AiLab.csproj -- --self-test

Then:

    dotnet run --project tools/Reborn.AiLab/Reborn.AiLab.csproj -- --train 20 --eval 20 --seed 1209 --out ai-lab/benchmark.json

Open ai-lab/benchmark.json. The file is a local benchmark output, not a
trained model for production. It is generated by the headless simulator and
can be regenerated from the same seed. The directory should remain ignored
when pushing local reports, to avoid unintended accumulation in Git.

## Interpreting the benchmark
- ScriptedReference: a simple scripted opponent vs the same reference player.
- AdaptiveBefore: a fresh adaptive opponent, before training.
- AdaptiveAfter: the trained adaptive profile against the SAME evaluation seeds
  and deck generation used for AdaptiveBefore.
- WinRateDifference: after - before; it can be negative.
- Unresolved: duels which did not end under the 100-half-turn cap. These remain
  explicitly unresolved, not counted as wins or losses.
- TrainingCompleted and LearnedDuels: only finished training games update the
  in-memory profile. Unresolved games do not train it.

The reference player and the synthetic deck distribution are NOT the authentic
PS1 opponents, official starter decks or deck weights. This is a narrow
repeatable benchmark for our current engine.

## Limitations
- This is a benchmark versus a scripted baseline, NOT true two-agent neural
  self-play, large-scale reinforcement learning or a deployed model.
- Cards with magics, traps, equips, rituals and their effects are excluded.
- The combat evaluator still assumes visible opponent monsters; face-down and
  uncertain information must be modeled before evaluating those situations.
- Different seeds and tests can give different outcomes. Twenty duels is a
  diagnostic sample, not statistically conclusive evidence of improvement.
- We do not automatically import benchmark learning into the player's profile:
  that would contaminate local progression with synthetic training data.
- Our five monster and five support zones, camera and Unity game remain unchanged.
